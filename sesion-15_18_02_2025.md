Código FUNDAE: NEGOCIO

* tips corregido

* feature selection
    * Técnica para filtrar columnas y quedarse con las mejores, es decir, es decir las que más ayudan a predecir la "y"
    * Técnica de reducción de dimensionalidad
    * No transforma datos, simplemente filtra columnas
    * No siempre es adecuado, normalmente solo se usaría si tenemos muchas columnas o columnas redudantes, o columnas prescindibles
    * Al tener menos columnas los modelos entrenan más rápido

* Aprendizaje supervisado:
    * Entrada X (features, características)
    * Salida y (label, target)
    * Algoritmo que aprende las relaciones entre la "X" y la "y"

* Aprendizaje no supervisado: PCA, Clustering
    * Entrada X (features, característica)
    * No hay "y", no hay etiquetas
    * Algoritmo que 'hace algo' sobre los datos
    * Por ejemplo algoritmos de 'clustering' detectan similitudes entre los datos de la X y crean clusters o grupos. Sería como una clasificación sin conocer de antemano etiquetas "y".
    * Por ejemplo 'PCA' o 'TruncatedSVD' reducen dimensionalidad, transformando datos a menos columnas.


* PCA se suele usar para dos cosas:
    * Reducción de número de columnas para agilizar los entrenamientos al eliminar información reduntante.
    * Visualizar datos en 2D o 3D con matplotlib o plotly en scatterplot. Esto ayuda entender mejor los datos y sus relaciones.

* Clustering:
    * Detectar similitudes para crear grupos, detectar patrones.
